# Adipose Tissue Immune Cell Deconvolution

**Method:** NNLS (Non-Negative Least Squares) + CIBERSORTx validation  
**Reference:** Human immune single-cell atlas  
**Depots:** Abdominal | Subcutaneous  
**Timepoints:** Baseline · Developing Obesity · Prolonged Obesity  
**Design:** Paired repeated measures (~Animal + Timepoint, 8 cats)

---

## Overview

This repository contains the R pipeline used to perform immune cell deconvolution of feline adipose tissue bulk RNA-seq data. Cat Ensembl gene IDs are mapped to human gene symbols to leverage a human immune single-cell reference, and cell-type proportions are estimated using NNLS — the same algorithm underlying CIBERSORTx. Output files are formatted for direct upload to the CIBERSORTx web portal for independent validation.

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/adipose-deconv.git
   cd adipose-deconv
   ```

2. Place all required input files in the `data/` directory.

3. Open `scripts/adipose_immune_deconvolution.R` and update the `setwd()` at the top if needed.

4. Run the script:
   ```r
   source("scripts/adipose_immune_deconvolution.R")
   ```

5. All outputs will be saved to `deconv_output/`.

## Methods Notes

**TPM normalization:** Computed using a constant 1 kb gene length since no GTF file is provided. If actual gene lengths are available, pass them to `calculate_tpm()`. If End-timepoint samples return all-zero TPM values, the script automatically falls back to log2(counts + 1).

**Gene mapping:** Cat Ensembl IDs are matched to human gene symbols via case-insensitive string matching using `gene_mapping_final.csv`. Human symbols from `org.Hs.eg.db` are used because the *Felis catus* genome has limited functional annotation; this is a standard approach for feline transcriptomics.

**NNLS deconvolution:** Proportions are estimated by non-negative least squares regression of each bulk sample against the signature matrix. Coefficients are normalized to sum to 1. This is algorithmically equivalent to CIBERSORTx's core method.

**Cell type combining:** `cDC1` and `cDC2` are merged into *Dendritic cells*; `Mac2` and `Mac3` are merged into *Proinflammatory Macrophage* to simplify interpretation.

**Statistics:** Pairwise comparisons between timepoints use paired Wilcoxon tests (reflecting the repeated-measures design). P-values are corrected using FDR across all tests.

**CIBERSORTx validation:** Upload `CIBERSORTx_mixture_adipose.txt` and `CIBERSORTx_signature_adipose.txt` to https://cibersortx.stanford.edu/ to cross-validate the NNLS results.
