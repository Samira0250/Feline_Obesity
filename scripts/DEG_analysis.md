# Adipose Tissue Differential Gene Expression Analysis

**Depots:** Abdominal | Subcutaneous  
**Comparisons:** MID vs BSL · END vs MID · END vs BSL  
**Design:** Paired repeated measures (~Animal + Timepoint, 8 cats)  
**Tools:** DESeq2 · ggplot2 · clusterProfiler · pheatmap

---

## Overview

This repository contains the R code used to perform differential gene expression (DGE) analysis of feline abdominal and subcutaneous adipose tissue across three dietary timepoints: Baseline (BSL), Middle (MID), and End (END). The analysis includes volcano plots, heatmaps, and Gene Ontology (GO) Biological Process enrichment for each pairwise comparison.

## Data

The primary input file is `List of DEGs for supplementary.xlsx`, which contains pre-computed DESeq2 results and normalized expression values organized by sheet. The full sheet list expected by the scripts is:

| Sheet name | Contents |
|---|---|
| `AB BSL-MID full` | Abdominal full results, BSL reference |
| `AB MID-END full` | Abdominal full results, MID reference |
| `SQ BSL-MID full` | Subcutaneous full results, BSL reference |
| `SQ MID-END full` | Subcutaneous full results, MID reference |
| `Group_1vsGroup_3` | AB normalized expression (pseudo counts) |
| `Group_4vsGroup_6` | SQ normalized expression (pseudo counts) |
| `AB B-M up/down` | Abdominal MID vs BSL DEG subsets |
| `AB M-E up/down` | Abdominal END vs MID DEG subsets |
| `SQ B-M up/down` | Subcutaneous MID vs BSL DEG subsets |
| `SQ M-E up/down` | Subcutaneous END vs MID DEG subsets |

> **Note:** Input data files are not tracked in this repository. Place all required files in the `data/` directory before running the scripts.

## Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/adipose-dge.git
   cd adipose-dge
   ```

2. Place all required input files in the `data/` directory.

3. Open each script and update the `setwd()` path at the top to point to your local `data/` directory, or set your working directory to the repo root in RStudio.

4. Run the scripts in order:
   ```r
   source("scripts/01_dge_volcanos_heatmaps_GO.R")   # MID vs BSL, END vs MID
   source("scripts/02_end_vs_bsl.R")                  # END vs BSL
   ```

5. All outputs will be saved to `plots2/`.

## Notes

- Log2 fold changes are **flipped** from the sheet's BSL-reference orientation so that positive values represent upregulation at the later timepoint (e.g., MID > BSL).
- GO enrichment uses human gene symbols via `org.Hs.eg.db` as a proxy for feline genes, which is a standard approach given limited annotation of the cat genome.
- DEG thresholds: **|log2FC| > 1** and **padj < 0.05**.
